# Instalación y Ejecución

## Descarga del archivo

Para ingresar al ejecutable, descargue el archivo comprimido en formato **`.zip`** desde el enlace proporcionado, e ingrese a la carpeta de build donde encontrará un archivo .exe que hace referencia al ejecutable del juego

## Descompresión

Una vez descargado el archivo, descomprímalo en su ordenador y acceda a la carpeta resultante.

## Ejecución del programa

Ejecute el archivo, que se encuentra dentro de la carpeta de build:

`Fuerzas_en_accion.exe`

Esto iniciará la experiencia interactiva.

## Controles de interacción

Una vez iniciado el programa, podrá interactuar con el entorno utilizando controles básicos de navegación:

- **Teclado** → desplazamiento y acciones, especificamente las flechas o lo que son las teclas AWSD
- **Mouse** → exploración e interacción visual de la cámara, con este podrás mover la cámara hacia diferenes vistas, ya que es un juego en primera persona
- **Shift** → Especialmente en el caso 2, donde necesitarás presionar el botón para agarrar el balón
- **Click derecho** → Para poder cambiar la posició de los vectores en el diagrama de cuerpo libre
- **tecla tab + click izquierdo** → Para serleccionar paneles, opciones, botones debes dejar presionado la tecla tab para visualizar el mouse

Explore libremente los diferentes escenarios disponibles.

## Solución de errores

Si durante la ejecución se presenta algún error y el programa no puede cerrarse de manera convencional, utilice la siguiente combinación de teclas para finalizar la aplicación:

**Alt + F4**
